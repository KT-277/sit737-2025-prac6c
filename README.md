# sit737-2025-prac6p

## 📌 Project Name
**sit737-6-1p-app**

## 🧾 Description
This project demonstrates a simple Node.js application deployed using Docker and Kubernetes. It is designed as part of Deakin University's SIT737 Cloud Native Application Development practical 6.1P.

The project includes:
- A basic Express app running on port 8080
- Dockerfile for containerization
- Kubernetes deployment and service configurations using `kind`
- Port-forwarding to access the app locally
